DATA STRUCTURES AND ALGORITHMS SECTION 1: PSEUDOCODE PROBLEMS
PC-1: PRIME NUMBER CHECKER
START
INPUT N
SET isPrime = true
FOR i = 2 TO sqrt(N) IF N MOD i = 0 THEN SET isPrime = false BREAK END
IF END FOR
IF isPrime = true THEN PRINT “Prime” ELSE PRINT “Not Prime” END IF
STOP
Example: N = 61 Output = Prime
N = 8 Output = Not Prime
PC-2: NUMBER DIGIT REVERSAL
START
INPUT N
SET reverse = 0
WHILE N > 0 SET digit = N MOD 10 SET reverse = reverse * 10 + digit SET
N = N DIV 10 END WHILE
PRINT reverse
STOP
Example: N = 1234 Output = 4321
N = 806 Output = 608
